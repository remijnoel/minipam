Integration Instructions

Your frontend at https://preview--ipam-visual-nexus.lovable.app should be able to connect to the MiniPAM backend without CORS issues.

Configuration:

  • Backend URL: http://localhost:8000
  • API Base Path: /api/v1
  • CORS: Already configured to allow all origins

Example API Calls:

// Get CIDR tree
fetch('http://localhost:8000/api/v1/cidrs/tree')
    .then(response => response.json())
    .then(data => console.log(data));

// Create a new CIDR
fetch('http://localhost:8000/api/v1/cidrs', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        cidr: '172.16.0.0/24',
        name: 'Test Network',
        description: 'Test description',
        parent: '172.16.0.0/16',
        tags: ['vlan:100', 'location:DC1']
    })
})
.then(response => response.json())
.then(data => console.log(data));
